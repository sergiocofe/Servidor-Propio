# 15 · n8n (automatización)

n8n es una plataforma de **automatización de flujos** (tipo Zapier autoalojado). En este servidor se usa para vigilancia y notificaciones (informes diarios, alertas de disco/CPU, contenedores caídos…) enviando avisos por Telegram.

---

## 1. Despliegue con Docker Compose

```bash
mkdir -p ~/docker/n8n && cd ~/docker/n8n
nano docker-compose.yaml
```

```yaml
services:
  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    container_name: n8n
    ports:
      - "5678:5678"
    environment:
      - N8N_HOST=n8n.lan
      - N8N_PORT=5678
      - N8N_PROTOCOL=https
      - WEBHOOK_URL=https://n8n.lan/
      - N8N_EDITOR_BASE_URL=https://n8n.lan/
      - GENERIC_TIMEZONE=Europe/Madrid
      - N8N_ENCRYPTION_KEY=Clave_Cifrado_n8n
      # Autenticación básica del editor (o usa la cuenta de propietario integrada)
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=Usuario_n8n
      - N8N_BASIC_AUTH_PASSWORD=Contraseña_n8n
    volumes:
      - ./data:/home/node/.n8n
    restart: unless-stopped
```

```bash
docker compose up -d
```

## 2. Triángulo de configuración

1. **DNS:** `n8n.lan` ➔ `IP_UBUNTU`.
2. **Certificado:**
   ```bash
   cd ~/certs && step ca certificate "n8n.lan" n8n.crt n8n.key
   ```
3. **Proxy (Nginx):**
    - Proxy Host: `n8n.lan` ➔ `http://IP_UBUNTU:5678`.
    - ⚠️ Activa **Websockets Support** (el editor lo necesita).
    - Marca **Force SSL**.

## 3. Flujos de ejemplo

Ideas de automatizaciones útiles para el servidor:

- **Informe diario** del estado del servidor por Telegram.
- **Alerta de uso de disco** (ejecuta un script `disco.sh` por SSH y avisa si supera un umbral).
- **Carga de CPU** consultando la API de Proxmox.
- **Resumen semanal** consolidado.
- **Contenedor caído**: comprobación cada 15 min y aviso inmediato.

Para Telegram, crea un bot con @BotFather y guarda el token como credencial → `Token_Telegram`. Para Proxmox, usa un *API Token* → `Token_API_Proxmox`.

!!! warning "Nodo SSH: cifrado de la clave"
    El nodo **SSH** de n8n **no admite** claves con cifrado `DES-EDE3-CBC`. Si exportas una clave ECDSA desde PuTTYgen, expórtala **sin passphrase** y en **formato OpenSSH**; si no, la conexión fallará.
